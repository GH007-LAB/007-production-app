# Fleet007 — รถบริษัท (พรบ. · ประกัน · ภาษี · ตรวจสภาพ · อื่น ๆ)

`production.007metals.com/fleet007` · ล็อกอินกลาง · **ใช้ได้เฉพาะ แอดมิน / HR / จัดซื้อ** · แจ้งเตือนอีเมลถึง **hr007@007metals.com** ทุกวัน 08:00 น.

## ใช้งาน
- **ข้อมูลรถ:** ทะเบียน · จังหวัด · ยี่ห้อ · รุ่น · ประเภทรถ · ปี · **สาขาที่ใช้รถ** (BK / SKN / PPS / สำนักงานใหญ่) · ผู้รับผิดชอบ · เลขตัวถัง · หมายเหตุ
- **รายการแจ้งเตือนต่อคัน:** พรบ. · ประกันภัย · ภาษีรถยนต์ (ป้ายวงกลม) · ตรวจสภาพรถ · เปลี่ยนถ่ายน้ำมันเครื่อง · อื่น ๆ (ตั้งชื่อเอง เช่น ใบอนุญาตขนส่ง)
  พร้อมวันครบกำหนด · เตือนล่วงหน้ากี่วัน (ค่าเริ่ม 60 / 30 / 15 / 7 / 1 วัน) · บริษัทประกัน · เลขกรมธรรม์ · เบี้ย
- **ต่ออายุแล้ว:** กดแล้วใส่วันหมดอายุใหม่ (ตั้งให้ +1 ปี) → หยุดเตือนรอบเดิม · เก็บประวัติ (วันเดิม → วันใหม่ · เบี้ย · ใครทำ)
- **เลิกใช้รถ** (ขาย/จำหน่าย): เก็บข้อมูลไว้ แต่ไม่แจ้งเตือนแล้ว
- หน้าแรกเรียงรถที่ใกล้ครบกำหนดที่สุดขึ้นก่อน · การ์ดสี แดง = เกินกำหนด · ส้ม ≤ 7 วัน · เหลือง ≤ 30 วัน · เขียว = ปกติ · กรองสาขา/ค้นหาได้

## อีเมลแจ้งเตือน (ทุกวัน 08:00 · Vercel cron `/api/fleet/cron`)
- รวมทุกรายการที่ถึงรอบเตือนวันนั้นเป็น **อีเมลเดียว** + แนบรายการที่ยังค้างเกินกำหนดอยู่
- ยังไม่ถึงกำหนด: เตือนครั้งเดียวต่อขั้น (60 → 30 → 15 → 7 → 1 → วันครบกำหนด) · cron พลาดวันไหนก็ส่งขั้นล่าสุดให้ ไม่ส่งซ้ำ
- เกินกำหนด: เตือนทุก 7 วันจนกว่าจะกด "ต่ออายุแล้ว"
- ส่งไม่สำเร็จ = บันทึก log แล้วส่งใหม่รอบถัดไป · ในแอปมีปุ่ม "ส่งอีเมลทดสอบ" · "ส่งแจ้งเตือนรอบนี้เลย" · ประวัติการส่ง

## สิทธิ์
ต้องผ่านทั้ง 2 ชั้น: ① ติ๊กแอป `fleet007` ให้รายคนที่ app.007metals.com/admin/access ② API เช็คทะเบียนพนักงาน:
`is_admin` หรือ ตำแหน่งมีคำว่า "บุคคล" / "HR" / "จัดซื้อ" / "Purchas" (แก้คำได้ที่ env `FLEET007_ROLE_WORDS` · เพิ่มรายคนที่ `FLEET007_EXTRA_IDS`)
บัญชีทดสอบ (`employees.is_test`) ดูได้อย่างเดียว · ตัวตนอ่านจาก `app_metadata` (C1) เหมือน approve007

## ติดตั้ง (CTO)
1. Supabase กลาง: รัน `sql/fleet007.sql` → ติ๊กสิทธิ์ `fleet007` ให้ แอดมิน / HR / จัดซื้อ
2. Vercel env — **อีเมล (เลือกอย่างใดอย่างหนึ่ง)**:
   - Resend: `RESEND_API_KEY` + `FLEET007_MAIL_FROM` เช่น `Fleet007 <fleet@007metals.com>` (ต้องยืนยันโดเมน 007metals.com ใน Resend)
   - หรือ SMTP: `SMTP_HOST=smtp.gmail.com` · `SMTP_PORT=465` · `SMTP_USER` · `SMTP_PASS` (Google Workspace + App Password)
   - `CRON_SECRET` ใช้ตัวเดียวกับ Sales007 · ไม่บังคับ: `FLEET007_ALERT_TO` (ค่าเริ่ม hr007@007metals.com · หลายคนคั่น ,)
3. Deploy → เปิดแอป → เพิ่มรถ → กด "ส่งอีเมลทดสอบ" ต้องเข้า hr007@007metals.com
