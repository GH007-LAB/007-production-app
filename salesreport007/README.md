## กติกาที่โค้ดบังคับ

- **ยอดขายคิดตามวัน เงินสดคิดตามรอบ** — รอบ 15:55 (`ready`) ให้เริ่มทำ 16:00 · รอบ 16:30 (`cutoff`) เติมเอกสาร 16:00–16:30 ต่อท้าย ไม่แตะแถวเดิม
- หลัง export รอบ `cutoff` แล้ว export ซ้ำของวันนั้นจะถูกปฏิเสธ (ต้อง `--force`) — เอกสารหลังตัดรอบไปเป็น **เอกสารยกมา** ของรายงานถัดไปเอง
- หาเอกสารยกมาจาก **ผลต่าง** ไม่ใช้เวลาในเอกสาร: เอกสาร RE/AI/SR/HS ย้อนหลัง 14 วัน ที่ไม่เคยอยู่ในรายงานใบไหน (อ่าน `out.json` ก่อน = สิ่งที่อยู่ในแท็บจริง ไม่มีค่อยใช้ `in.json`) · วันแรกไม่มีเอกสารยกมา
- เอกสารเดิมถูกแก้ยอด/ยกเลิกใน Express หลัง export → ไม่แก้แถว แต่ขึ้น `warnings` ใน in/out.json และใน `reconcile`
- HS ของลูกค้าใน `interbranch_customers` = ขายระหว่างสาขา ไม่ขึ้น · HS อื่นขึ้นเป็นแถวรับเงิน มีโน้ต "แจ้ง ผบ."
- แท็บพนักงาน **ไม่มีสูตร ไม่มียอดรวมเงิน** · ช่องทางไม่มีค่าเริ่มต้น · ทั้งแท็บป้องกัน เปิดเฉพาะ ช่องทาง/ยอดเงินสดผสม/ค่าใช้จ่าย/ยอดนับ/ผู้จัดทำ/รูป QR/ช่องส่ง
- ติ๊ก "ส่งรายงาน" ได้เมื่อ: รอบ 16:30 มาแล้ว · เลือกช่องทางครบ · ผสม 0 < เงินสด < ยอดเอกสาร · กรอกยอดนับ · เลือกผู้จัดทำ — ไม่ผ่าน = ช่องเด้งกลับ + บอกเหตุผลที่ G3
- ส่ง หรือถึง 16:55 → ล็อกทั้งแท็บ (ไม่มีใครแก้ได้นอกจากเจ้าของ) → คำนวณ → `YYMMDD_out.json` + แถวในไฟล์สรุป · แก้หลัง 16:55 ถูกคืนค่าแล้วล็อกทันที · ส่งแล้วเผย **เฉพาะส่วนต่าง**
- ค่าใช้จ่ายที่ไม่มีชื่อไฟล์รูป หรือชื่อไฟล์ไม่มีจริงในโฟลเดอร์รูปบิลของสาขา = ไม่นับ (ข้อ 9.6)
- SR แบบ "ผสม" นับเฉพาะส่วนเงินสดเป็นคืนเงินสด (สเปกเขียนไว้แค่ SR เงินสด — ส่วนนี้เพิ่มให้ครบกรณี)

## ติดตั้ง (CTO · ก่อน 15:55 วันเสาร์ 3 ต.ค.)

1. **Mac mini:** `bash salesreport007/engine/launchd/install_macmini.sh` → ต้องขึ้น `PRE-FLIGHT OK` แล้วตามด้วยยอดของเมื่อวานแยกประเภท
2. **Step 0 (ข้อ 2):** เทียบยอด `inspect` กับฟอร์มปัจจุบันของเมื่อวาน 1 วันต่อสาขา
   - RE/AI/SR ตรงกับฟอร์มไหม · RE อยู่ ARTRN หรือ ARRCPT · ค้างรับ IV ใช้ ARRCPIT หรือ REMAMT · DOCSTAT ยกเลิกเป็น `C` จริงไหม
   - ไม่ตรง → แก้ `AutoExport/scripts/salesreport007/engine/config/sources.json` (ติดตั้งซ้ำจะไม่ทับไฟล์นี้) แล้ว `inspect` ใหม่
   - ใส่รหัสลูกค้าสาขาด้วยกันใน `interbranch_customers`
3. **Drive:** ก๊อป `apps_script/config.example.json` → `AutoExport/sales_report/config.json` ใส่ชื่อ+อีเมลพนักงาน · float (ค่าเริ่ม 0 ตามข้อ 5) · อีเมล ผบ./Finny
   - สร้างโฟลเดอร์รูปบิลต่อสาขา **นอก** `sales_report` (เช่น `รูปบิลค่าใช้จ่าย/SKN`) แชร์ให้พนักงานสาขานั้นเป็นผู้แก้ไข → ใส่ id ใน `receipt_folder_id`
   - **ห้ามแชร์โฟลเดอร์ `sales_report`** — มี out.json ที่มียอดเงินสดที่ควรมี
4. **Apps Script:** ล็อกอินบัญชีบริษัท (007skn0777) → script.google.com → โปรเจกต์ใหม่ → วาง `Code.gs` + `appsscript.json` (เปิด "Show appsscript.json" ใน Project Settings)
   → Script Properties: `ROOT_FOLDER_ID` = id โฟลเดอร์ `sales_report` → รัน `setup()` แล้วอนุญาตสิทธิ์
   - `runNow()` = เติมแท็บทันที · `finalizeNow()` = ล็อก+สรุปทุกสาขาทันที (ใช้ตอนทดสอบ/ฉุกเฉิน)
5. ทดสอบ: `python3 .../salesreport.py export ready --branch SKN` → `runNow()` → เปิดไฟล์ในโฟลเดอร์ `_sheets/SKN` เห็นแท็บวันนี้

### ขั้นต่ำวันแรก (ถ้า Apps Script ยังไม่พร้อม · ข้อ 7)
ทุกรอบ export จะเขียน `YYMMDD_new_HHMM.csv` (เฉพาะแถวที่เพิ่มรอบนั้น) ไว้ข้าง in.json → วางลงแท็บเองก่อน 16:00 และอีกครั้งหลัง 16:30 → ถอนสิทธิ์ 16:55 → คำนวณสรุปด้วยสูตรใน `engine/calc.py`
